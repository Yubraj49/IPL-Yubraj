# 🏏 IPL Details Website

## 📖 About the Project

This project is a comprehensive **Indian Premier League (IPL) information website** created for cricket fans. It provides organized information about IPL teams, players, coaches, trophies, records, and other important details about the league.

The website is designed with a clean and user-friendly interface so visitors can easily explore different teams and learn about their players, coaching staff, achievements, and history.

## ✨ Features

* 🏏 IPL team information
* 👤 Detailed player information
* 👨‍🏫 Coaches and support staff details
* 🏆 Trophy and championship information
* 📊 Team records and achievements
* 📜 IPL history and important information
* 🔍 Easy navigation between different sections
* 📱 Responsive and user-friendly design

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, layout, and animations
* **JavaScript** — Interactive features and functionality

## 🎯 Project Goal

The main goal of this project is to create a simple and informative platform where IPL fans can explore information about teams, players, coaches, trophies, and the history of the tournament in one place.
